# SPY 下一交易日 VaR 预测

研究目标：在交易日结束后，使用此前已知的信息，预测下一交易日对数收益率的 **1%、5%、10% 左尾分位数**。这三个概率预先给定，模型输出三个收益率界限。例如，5% 分位数预测为 −2%，表示模型预计下一日收益率低于 −2% 的概率为 5%。

研究围绕三个问题展开：动态波动建模是否优于直接使用近期收益分布；相同信息下，非线性关系是否优于线性关系；相同多日历史下，循环或注意力结构是否带来额外收益。目前没有最终选型结论。

## 模型状态

| 方法 | 代码状态 | 研究作用 |
|---|---|---|
| 历史模拟 `historical` | 已实现 | 使用近期收益经验分布的基线 |
| 线性分位数回归 `linear_qr` | 已实现 | 使用收益、log(RV5)、log(BV) 的线性基线 |
| 分位数 MLP `mlp_qr` | 已实现，当前是单日输入 | 相同信息下的非线性对照 |
| GARCH | 计划中，尚未实现 | 动态条件方差建模 |
| 分位数 GRU `gru_qr` | 已实现，支持多日输入 | 多日输入的循环结构 |
| Transformer | 计划中，尚未实现 | 多日输入的注意力结构 |

已实现的方法可独立运行；计划中的方法尚无训练结果。

## 使用与目录边界

本目录是可公开的实验代码：配置、数据探索、模型、滚动预测、评价与测试。研究报告的文字、排版脚本及 PDF 单独管理，不是运行依赖。

安装本目录的 `requirements.txt` 中的依赖后，将含日期索引及 `log_ret`、`rv5`、`bv` 三列的 CSV 路径填入 `config/experiment.yaml` 和 `config/exploration.yaml`。默认数据位于本目录上一层的 `spy_data.csv`；数据不随代码分发。

```text
工作目录/
  var_forcast/   # 公开的代码仓库
  spy_data.csv   # 输入数据
  results/       # 生成的实验记录、统计与图
  reports/       # 独立的报告制作与交付材料；运行代码不需要此目录
```

## 一次只运行一个模型

在本代码仓库目录中运行：

```bash
python run.py
```

也可以从其父目录运行 `python -m var_forcast.run`。不接受命令行参数、不接受模型列表或 `all`。

`config/experiment.yaml` 只配置本次实验：

```yaml
model: gru_qr
test_size: 1000
alphas: [0.01, 0.05, 0.10]
data: ../../spy_data.csv
output: ../../results
```

- `model`：本次唯一运行的模型。
- `test_size`：最后多少个交易日参与逐日预测；不是一次预测未来这么多天。
- `alphas`：收益率左尾概率。
- 路径相对于本 YAML 文件，不依赖终端当前目录。

模型自己的参数在 `config/<模型名>.yaml`。例如 `config/gru_qr.yaml`：

```yaml
window: 1000
lookback: 20
epochs: 20
hidden: 16
learning_rate: 0.01
weight_decay: 0.001
seed: 42
```

只读取选中模型的配置。改历史模拟的窗口不会改变 MLP 的窗口。每次结果自动保存到 `../results/<模型名>/<本次运行>/`，不会覆盖旧结果。运行目录包含公共配置和模型配置的快照。

## 滚动窗口怎样工作

监督表的一行对应预测目标日 s。输入是 s−1 日的收益率、log(RV5)、log(BV)，标签是 s 日真实收益率。

预测第 i 行时，训练样本严格取 `[i-window, i)`：

1. 用最近 `window` 条已经兑现的样本拟合模型。
2. 特征标准化只使用当前训练窗口。
3. 使用目标日前一交易日的信息，预测目标日的三个分位数。
4. 预测完成后才读取目标日实际收益用于评估。
5. 下一天窗口向前移动一条，重新拟合。

这里的 `window` 是训练标签数；GRU 的 `lookback` 是每个样本看过去多少个交易日，两者独立。GRU 默认 W=1000、L=20，因此最早的训练样本还需要额外 19 行特征历史，训练标签仍为 1000 个。每个序列按从早到晚排列，最后一个输入日严格早于标签日。

GRU 使用单层、16 个隐藏单元和三个分位数输出头，以 pinball loss 训练。特征按训练序列内各指标的均值和标准差缩放，重叠日期按出现次数参与计算；目标收益乘以 100 训练，预测后除以 100 还原。每个样本的隐藏状态从零开始，每个预测日重新初始化网络和优化器，不跨日传递状态。默认全批次训练 20 轮，固定随机种子；这些是首轮设置，尚未调参。

MLP 当前只使用单日输入，GRU 使用 20 日输入；直接比较二者同时改变了信息量和网络结构。若要判断循环结构本身的贡献，还需要相同 20 日输入的 MLP 对照。

## 窗口必须相同吗，怎么选择

**统一窗口适合控制变量，不代表这个长度对每种模型都最好。** 初始配置暂用 1000 条样本，方便复现和学习；这个数字尚未经过验证选择。

研究比较应分两步：

1. 相同预测日期、相同训练窗口下比较模型；比较线性分位数回归和 MLP 时也保持相同输入。
2. 在更早的时间验证段内，为各模型选择窗口和超参数，再固定配置评估。可预先列出少量候选长度，例如 250、500、1000；这只是候选设计，不是已经完成的调参。

短窗口更贴近近期状态，但用于估计尾部的样本少；长窗口尾部样本更多，但可能混入较旧的市场状态。窗口选取会改变表现。比较各模型分别选出的窗口时，结论针对完整方案，而不能全部归因于模型结构。

当前最后 1000 日已经在之前的探索中查看过，继续运行只能叫探索性评估。不能一边看这段成绩改参数，一边将它称为未接触的最终测试集。当前入口没有自动调参或验证集搜索。

## 评价标准

- **Pinball loss**：同一尾概率下越小越好，是主要的分位数预测损失。
- **突破率**：实际收益低于预测界限的比例，目标接近对应尾概率，并非越低越好。
- **覆盖率、独立性和条件覆盖检验**：检查突破频率及是否成簇；较大的 p 值不证明模型正确。尾部事件稀少时，检验尤其不稳定。
- 比较不同运行时必须核对预测日期、尾概率、输入信息和训练设置。

独立拟合的分位数可能交叉。当前统一使用递增重排，保留 `raw_var`、`raw_crossing`，评估使用排序后的 `var`。

## 目录按用途分组

```text
var_forcast/
  run.py
  config/        # 全部 YAML 和配置读取器
  exploration/   # 数据探索
```

## 代码阅读顺序

| 文件 | 职责 |
|---|---|
| `config/experiment.yaml`、`config/` | 公共实验设置与各模型参数 |
| `config/__init__.py` | 读取选中配置并检查非法参数 |
| `experiment/data.py` | 数据校验、日期对齐、构造特征和标签 |
| `models/historical.py` | 历史样本分位数 |
| `models/linear_qr.py` | 分位数损失加 L1 惩罚的线性模型 |
| `models/mlp_qr.py` | 前馈网络与分位数损失 |
| `models/gru_qr.py` | 多日序列、GRU 编码器与分位数输出 |
| `models/common.py` | 训练窗口内的标准化 |
| `experiment/backtest.py` | 一个模型的逐日滚动训练和预测 |
| `experiment/metrics.py` | 预测损失、覆盖和独立性检验 |
| `experiment/artifacts.py` | 实验目录、配置快照和运行记录 |
| `experiment/plots.py` | VaR 曲线及该模型的评价图 |
| `run.py` | 串联一次实验，不包含模型算法或多模型循环 |

## 查看结果

每次运行会打印结果目录：

- `predictions.csv`：逐日预测、实际值、原始输出、训练起止日期。
- `metrics.csv`：各尾概率的损失、突破率和检验结果。
- `config_snapshot.yaml`、`model_config_snapshot.yaml`：本次实际使用的设置。
- `run_manifest.json`：运行状态、耗时、依赖版本、数据和源码哈希。失败运行标记为 `failed`。
- `var_forecasts.png`、`model_comparison.png`：预测曲线与评价图；后者保留旧文件名，但单次仅展示当前模型。

运行记录保存在代码库外，不作为源码提交。每次运行保留独立目录，便于复现与比较。

## 数据探索

数据探索的正式入口是 `exploration/run.py`，窗口在 `config/exploration.yaml` 中配置：

```bash
python exploration/run.py
```

输出默认位于代码库外的 `../results/exploration/`。探索只生成统计表和图，不负责研究报告的文字与 PDF 排版。

RV5/BV 的精确构造及缩放未在题目中说明；当前将其作为给定的正值指标取自然对数使用，不擅自年化或解释成跳跃幅度。

```bash
python -m pytest -q
```
